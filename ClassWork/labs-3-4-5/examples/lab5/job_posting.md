# Junior Software Engineer — AI Products

**Company:** Nexus AI
**Location:** San Francisco, CA (Hybrid)
**Team:** Applied Machine Learning

## About the Role

We're looking for a Junior Software Engineer to join our Applied ML team. You'll work on building user-facing features powered by machine learning models, collaborating with ML researchers and product designers to ship products that delight users.

This is a great role for someone early in their career who wants to work at the intersection of software engineering and AI.

## Responsibilities

- Build and maintain web applications that integrate ML models
- Develop APIs and backend services in Python
- Collaborate with ML engineers to deploy models to production
- Write clean, tested, maintainable code
- Participate in code reviews and technical discussions

## Requirements

- Bachelor's degree in Computer Science or related field
- Experience with Python and at least one web framework (Flask, FastAPI, Django)
- Familiarity with React or similar frontend framework
- Basic understanding of machine learning concepts
- Strong communication skills and ability to work in a team

## Nice to Have

- Experience deploying ML models (PyTorch, TensorFlow)
- Familiarity with cloud platforms (AWS, GCP)
- Contributions to open source projects
- Experience with Docker and containerization

## Interview Process

1. Recruiter screen (30 min)
2. Technical phone interview (45 min)
3. Onsite: System design + coding + behavioral (4 hours)
4. Team lunch

## Compensation

$95,000 - $120,000 base salary + equity + benefits
